I've been thinking a lot about [this piece by Mattias Geniar](https://ma.ttias.be/web-development-is-fun-again/) on how web development is fun again. The core thesis hit me hard: *coding was never the fun part—building something from nothing was*.

For years now, I've watched the complexity of web development balloon. Frontend requires mastering build pipelines, bundlers, CSS frameworks, and performance optimization. Backend demands design patterns, testing strategies, API architectures, and infrastructure knowledge. It became exhausting just to keep up, let alone to actually *build* something.

Here's what changed for me: AI didn't make me write better code. It made me care about code less.

That sounds negative, but it's actually liberating. All those hours I spent fighting with webpack configs or debugging CSS specificity issues? Those weren't the creative parts. They were the tax I paid to bring ideas to life.

With Claude helping me navigate the complexity, I'm back to thinking about *what* I want to build instead of *how* to build it. Questions like "should I add this feature?" used to come with a mental calculation: "Is this worth 4 hours of work?" Now the friction is gone. I can experiment. I can add little quality-of-life improvements that previously seemed impractical.

This site is a perfect example. I wanted a personal space that pulls in what I'm currently reading, listening to, watching, working out. Could I have built this before? Sure, eventually. But between work and life and everything else, the activation energy was too high. Now? I can knock out features in focused 30-minute sessions.

Simon Willison [wrote about this too](https://simonwillison.net/2026/Jan/4/coding-again/)—how AI coding tools are helping people write code again by lowering the time commitment barrier. You don't need multi-hour blocks anymore. You don't need to spend the first hour rebuilding your mental model of the codebase. You can be productive in the gaps.

I'm not coding less. I'm actually coding *more*. But the ratio has flipped: more time creating, less time fighting with tooling.

Web development is fun again because I remember why I started doing this in the first place—not to master build systems, but to make things that didn't exist before.
